# Homepage EXIF report screenshots

The `exif-report-{en,de,fr,zh-cn}-v1.png` images (1200 × 720) and
`exif-viewer-{en,de,fr,zh-cn}-v1.png` social images (1200 × 630) show the
actual ViewExif report for the site's public metadata demonstration JPEG.
Each locale was read through the existing **Try sample** action, including
the completed local ExifTool inspection, before capture.

The source is `public/samples/metadata-demo-v1.jpg`, documented in
[the sample's source notes](../samples/SOURCES.md). The scene is AI-generated;
its camera, capture-date, exposure and public-landmark GPS values were added
for demonstration. These images do not establish photographic origin or
an actual capture location.

The capture layout places the existing preview and EXIF summary DOM together
with the site's own branding, colors and texture. It changes presentation
for the fixed image dimensions; it does not replace parsed field values.
The screenshots contain a localized disclosure of the demonstration data.

Homepage screenshots use these independent PNG assets. Loading a screenshot
does not fetch or inspect the original sample JPEG; sample inspection still
requires the user's explicit action.
